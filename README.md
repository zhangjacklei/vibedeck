# vibedeck

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![macOS 12.0+](https://img.shields.io/badge/macOS-12.0%2B-blue.svg)

用 Apple TV Siri Remote（含 A2540）把 Mac 变成一个可自定义的控制面板：触控板指针、滚动、按键映射到媒体控制 / 鼠标操作 / 任意键盘快捷键，以及语音输入。一个常驻菜单栏的小工具，点开即可配置。

本项目是 [Remotastic](https://github.com/laurentschuermans/Remotastic) 的本地改造分支，在此基础上增加了可视化配置界面、A2540 适配、快捷键录制、语音输入、省电与休眠管理等能力。

## 功能

- **触控板控制**：移动光标、点击、拖拽、双指滚动，支持多显示器
- **按键映射**：把遥控器任意按键映射到媒体控制、鼠标动作或任意键盘快捷键 / 组合键（支持实体键盘录制）
- **打开 App**：从系统已安装应用列表中选择，无需手动填写路径
- **语音输入**：通过 Mac 麦克风 + 系统语音识别转文字（遥控器麦克风在 macOS 上不可用，见[局限](#局限与平台说明)）
- **省电与休眠**：菜单栏「暂停接管 / 睡前一键释放」，闲置 N 分钟自动释放 HID 并停止触控板轮询，按任意键自动恢复
- **菜单栏入口**：连接状态、暂停 / 恢复、打开权限设置等
- **可视化界面**：CleanMyMac 风格的概览 / 按键映射 / 语音 / 省电 / 关于五个页面

## 环境要求

- macOS 12.0 或更高版本
- Xcode Command Line Tools：`xcode-select --install`
- 一台 Apple TV Siri Remote（开发主要针对 A2540，其他型号可能可用但未逐一验证）
- Apple Silicon 与 Intel Mac 均支持（构建产物为 Universal 通用二进制）

## 构建与安装

### 方式一：从源码构建

```bash
git clone https://github.com/<你的账号>/videdeck.git
cd videdeck

./build.sh universal          # 构建 arm64 + x86_64 通用二进制
./create_app_bundle.sh        # 打包 vibedeck.app 并签名（ad-hoc）
open vibedeck.app
```

只在本机开发调试、不分发时，用 `./build.sh`（不接 `universal`）可更快编译当前架构。

> `create_app_bundle.sh` 默认使用 ad-hoc 签名，不依赖任何本机 Keychain 身份，因此在任意一台 Mac 上构建行为一致。如需自有 Developer ID 签名：
> `VIBEDECK_SIGN_IDENTITY="Developer ID Application: ..." ./create_app_bundle.sh`

### 方式二：使用分发包

`./package_release.sh` 会在 `dist/` 下产出 `vibedeck.app`、`install.command`、`README-install.txt`，以及 `vibedeck-macOS-universal.dmg` / `.zip`。解压后双击 `install.command` 即会清除 quarantine、备份旧版、复制到 `/Applications` 并启动。

分发包（DMG / ZIP）属于构建产物，不纳入 Git 版本管理，建议通过 GitHub Releases 发布。

首次通过方式一打开、或手动拖入 `/Applications` 的未公证应用，如被系统拦截，执行：

```bash
xattr -dr com.apple.quarantine /Applications/vibedeck.app
```

## 首次使用：三项权限缺一不可

**这是本类项目最常见的 issue 来源：遥控器显示「已连接」但按键 / 指针完全没反应，几乎都是因为权限没给全。** 安装后请依次在「系统设置 → 隐私与安全性」中开启以下三项，然后**完全退出并重新启动 vibedeck**（改权限后必须重启 App 才生效）：

### 1. 蓝牙（Bluetooth）

- 位置：**系统设置 → 隐私与安全性 → 蓝牙**
- 操作：找到 `vibedeck`，打开允许使用蓝牙的开关
- 用途：探测遥控器是否在系统蓝牙配对列表中，给出「已连接 / 未连接」状态和引导
- 说明：macOS 13 起才有这一项；若你的系统没有该条目可跳过，不影响 HID 按键接管本身

### 2. 输入监控（Input Monitoring）

- 位置：**系统设置 → 隐私与安全性 → 输入监控**
- 操作：点 `+`，把 `vibedeck.app` 添加进去并勾选；或在 App 弹出请求时点「允许」
- 用途：读取遥控器 HID 按键与触摸板事件——**没有它，按键和触控板都不会有任何反应**
- 添加后若界面仍显示未授权，先退出 App 再重开；可用 `--diag` 命令核对实际探测结果（见[自检与诊断](#自检与诊断)）

### 3. 辅助功能（Accessibility）

- 位置：**系统设置 → 隐私与安全性 → 辅助功能**
- 操作：把 `vibedeck.app` 加入并勾选
- 用途：注入按键（快捷键 / 打开 App）、移动指针、把语音文字输入到当前应用——**没有它，映射的按键动作不会执行**

> 提示：如果从源码构建后移动过 `vibedeck.app` 的位置或重新签名，macOS 会把它当作新应用，需要在上述三项里重新授权（TCC 按「路径 + 签名」记录授权）。

## 配对遥控器

1. 打开 **系统设置 → 蓝牙**，让遥控器进入配对模式（不同型号方式不同，Siri Remote 通常是按住 **电视/返回键 + 音量+** 数秒）。
2. 在系统蓝牙中完成配对。配对成功后遥控器会出现在设备列表里。
3. 启动 vibedeck。菜单栏出现遥控器图标、概览页显示「遥控器已连接」即可开始使用。
4. 若显示「未连接」但蓝牙列表里能看到设备，按一下遥控器任意键唤醒 HID，再回到 App 查看。

## 功能说明

- **按键映射页**：点击遥控器示意图上的按键 → 选择动作（媒体控制 / 鼠标 / 打开 App / 键盘快捷键）。快捷键可点「录制按键」直接按键盘组合录入，支持 `⌘⇧P`、`ctrl+alt+right`、F1–F12、方向键等，多组动作用逗号分隔顺序执行。
- **语音页**：选择输入源（Mac 麦克风）、测试录音与识别、开关右上角 HUD。首次使用需授予麦克风 + 语音识别权限。
- **省电页**：设置闲置自动休眠时间，或点「睡前一键释放」立即释放 HID 接管并停止触控板轮询；按遥控器任意键自动恢复。
- **菜单栏**：连接状态、「暂停 / 恢复接管」、「睡前一键释放」、「立即测试休眠」、打开蓝牙设置与权限设置。

## 自检与诊断

不连接遥控器也能跑的命令行自检，便于排查问题：

```bash
./vibedeck --selftest      # 业务可用性自检（快捷键解析、状态机、权限逻辑等）
./vibedeck.app/Contents/MacOS/vibedeck --diag        # 权限 / 蓝牙 /  HID 诊断
./vibedeck.app/Contents/MacOS/vibedeck --power-test  # 省电硬件链路测试（真实进程）
```

`--diag` 会打印输入监控、辅助功能、麦克风、语音识别的原始探测值，以及系统蓝牙中可见的遥控器设备，方便对照界面显示排查「权限显示不一致」问题。

> 语音相关测试请通过 `.app` 启动运行；直接运行裸二进制的语音测试入口会拒绝执行并给出提示，这是有意为之（TCC 授权按 App 身份判定）。

## 常见问题

- **「连上了但没反应」**：99% 是权限问题。回到[三项权限](#首次使用三项权限缺一不可)逐项核对，改完**重启 App**。用 `--diag` 看输入监控 / 辅助功能是否为「可用 / 已授权」。
- **界面显示「未授权」但系统里已开启**：TCC 按「路径 + 签名」记录，移动过 App 或重新签名后需重新授权；也可用 App 内的「重新检测」按钮刷新。
- **概览页与省电页状态不一致**：两页共用同一个连接状态数据源；若不一致，通常是版本问题，请确认运行的是最新构建。
- **遥控器耗电快**：启用省电页的闲置自动休眠，睡前用「睡前一键释放」。macOS 上第三方 App 无法真正断开系统级 BLE HID 连接，详见[局限](#局限与平台说明)。
- **语音识别状态时而授权时而未授权**：系统 TCC 状态在不同启动方式下会短暂波动，App 内提供「重新检测」入口，以实际授权结果为准。

## 局限与平台说明

- **非 App Store 应用**：使用了 macOS 私有框架 `MultitouchSupport.framework` 读取触控板原始事件，无法通过 App Store 审核。
- **遥控器麦克风不可用**：A2540 的麦克风在 macOS 上不会作为标准音频输入设备暴露，系统只允许 Siri 自身访问。因此语音输入使用 **Mac 本机麦克风**。
- **无法精确断开 BLE HID**：遥控器配对后由 macOS 系统级持有，第三方 App 不能可靠地断开其蓝牙连接。「释放 / 休眠」释放的是本 App 对 HID 的独占接管并停止轮询，从软件层面避免持续唤醒设备；要彻底断电仍需关闭遥控器或系统蓝牙。
- **按键行为依赖映射配置**：电源键等特殊按键的实际行为取决于你在按键映射页的配置；系统级媒体键可能仍由系统响应。
- **机型覆盖有限**：主要针对 A2540 开发与测试，其他 Siri Remote 型号可能可用但未逐一验证。
